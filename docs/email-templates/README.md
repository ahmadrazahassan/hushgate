# Hushgate email templates

Generated by `node scripts/build-email-templates.mjs`; edit the script, not the HTML files.

In Supabase: **Authentication → Emails → Templates**. Open each template, paste the **Subject**, switch the body to **Source**, and paste the whole HTML file.

| Supabase template | Subject | File |
|---|---|---|
| Confirm sign up | `Confirm your Hushgate account` | `confirm-signup.html` |
| Invite user | `You're invited to Hushgate` | `invite-user.html` |
| Magic link or OTP | `Your Hushgate sign-in link` | `magic-link.html` |
| Change email address | `Confirm your new Hushgate email` | `change-email.html` |
| Reset password | `Reset your Hushgate password` | `reset-password.html` |
| Reauthentication | `{{ .Token }} is your Hushgate code` | `reauthentication.html` |
| Password changed | `Your Hushgate password was changed` | `password-changed.html` |
| Email address changed | `Your Hushgate email was changed` | `email-changed.html` |
| Phone number changed | `Your Hushgate phone number was changed` | `phone-changed.html` |
| Sign-in method linked | `A sign-in method was added to your Hushgate account` | `identity-linked.html` |
| Sign-in method removed | `A sign-in method was removed from your Hushgate account` | `identity-unlinked.html` |
| MFA method added | `A verification method was added to your Hushgate account` | `mfa-added.html` |
| MFA method removed | `A verification method was removed from your Hushgate account` | `mfa-removed.html` |

The logo loads from Supabase Storage (public bucket `brand`), so it shows in every inbox without the website being live.
